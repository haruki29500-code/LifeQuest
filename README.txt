LIFE QUEST - เวอร์ชันพร้อมส่งให้คนอื่น

วิธีใช้งานง่ายที่สุด:
1. ส่งไฟล์ index.html ให้เพื่อน หรือส่งทั้งโฟลเดอร์/ไฟล์ ZIP นี้
2. ถ้าส่งเป็น ZIP ให้แตกไฟล์ก่อน
3. เปิด index.html ด้วย Chrome / Edge

หมายเหตุ:
- เวอร์ชันนี้ปิด Service Worker ใน index.html เพื่อแก้ปัญหา OneCompiler/MIME type และให้เปิดแบบไฟล์ได้
- ฟังก์ชันหลักของแอปอยู่ใน index.html
- ฟอนต์/ไลบรารีจาก CDN และ Spotify ต้องใช้อินเทอร์เน็ต
- ถ้าต้องการให้เป็น "ลิงก์เว็บ" ที่ทุกคนกดแล้วเปิดทันที ควรนำโฟลเดอร์นี้ไปโฮสต์บน GitHub Pages หรือบริการ static hosting
